# 🛒 E-Commerce & Inventory Management System

A comprehensive **Laravel-based** full-stack web application designed to streamline online retail operations and real-time stock tracking. It combines a user-friendly customer storefront with a powerful admin dashboard for seamless product, supplier, and order management.

---

## ✨ Key Features

### 🛍️ Customer Storefront
* **Interactive Product Catalog:** Browse products with real-time search functionality.
* **Dynamic Shopping Cart:** Add, update quantities, or remove items seamlessly before checkout.
* **Order Processing:** Smooth checkout workflow with order tracking.

### 🛠️ Admin Dashboard & Inventory Control
* **Real-Time Overview:** Monitor total products, categories, and suppliers at a glance.
* **Inventory & Product Management:** Add, update, and manage product stock levels, pricing, and images.
* **Category & Supplier Management:** Organize inventory efficiently by categories and suppliers.
* **Automated PDF Invoicing:** Generate and download itemized PDF invoices automatically upon order completion.
* **Real-Time Email Notifications:** Send automated transactional email updates to customers regarding their order status.

---

## 💻 Tech Stack

* **Backend:** PHP, Laravel
* **Frontend:** HTML5, CSS3, JavaScript, Blade Templates
* **Database:** MySQL
* **Additional Tools:** DomPDF (for PDF generation), Laravel Mail (for email notifications)
